# TikTok-style Video Edit for GitHub Pages

### Инструкция по установке:
1. Перенеси свои видеоролики в папку `videos/` и назови их:
   * `video1.mp4`
   * `video2.mp4`
   * `video3.mp4`
   * `video4.mp4`
   * `video5.mp4`
2. Перенеси трек в папку `audio/` и переименуй его в `music.mp3`.
3. Чтобы изменить текст эдита или подогнать смену видео под биты музыки, открой файл `index.html` через текстовый редактор и найди массив `const timeline`. Там можно настроить секунды (`time`), текст субтитров (`text`), номер видео (`videoIndex`) и эффект тряски экрана (`shake: true/false`).
4. Загрузи все файлы на GitHub и включи Pages в настройках репозитория.
